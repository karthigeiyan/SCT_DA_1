# SCT_DA_1 - Excel Sales Dashboard

## Project Overview
This project was completed as part of the **SkillCraft Technology Data Analytics Internship (Task 01)**.

The objective of this project was to clean, analyze, and visualize sales data using Microsoft Excel. An interactive dashboard was created using Pivot Tables, Pivot Charts, Slicers, KPI Cards, and Conditional Formatting to provide meaningful business insights.


## 🎯 Objective
Create an interactive Excel Sales Dashboard to:
- Analyze Total Sales Performance
- Track Sales Trends Over Time
- Compare Sales Across Categories and Regions
- Identify Top Performing States and Product Categories
- Enable interactive filtering using Slicers
- Highlight key business insights through visualizations


## 📊 Dataset
**Dataset Used:** Superstore Sales Dataset

### Visualizations

### Formatting Features

- Dynamic Filtering


## 🔍 Key Insights
- Technology category generated the highest sales.
- Consumer segment contributed the largest share of revenue.
- California emerged as the top-performing state in terms of sales.
- Sales demonstrated an overall positive growth trend over the analyzed period.
- Interactive filters allow quick exploration of business performance across different categories and customer segments.
